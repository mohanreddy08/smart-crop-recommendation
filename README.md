## 🔍 Project Overview

The Smart Crop Recommendation System helps farmers, agronomists, and researchers make data-driven decisions on crop selection. By analyzing 6 vital parameters—**Nitrogen (N)**, **Phosphorus (P)**, **Potassium (K)**, **Temperature**, **Soil pH**, and **Rainfall**—the system predicts the crop with the highest likelihood of yield success, providing prediction confidence and top alternative options.

## 📊 Dataset & Model Performance

- **Records:** 2,200 rows across 22 crops (100 balanced samples per crop).
- **Split:** 80% Train (1,760 records), 20% Held-out Test (440 records), stratified.
- **Model Selected:** **Random Forest Classifier** (`n_estimators=200`, stratified 5-fold cross-validation accuracy: **98.2%**, test set accuracy: **98.4%**).
- **Feature Importance:**
  1. Rainfall (~27.1%)
  2. Potassium (K) (~21.0%)
  3. Phosphorus (P) (~17.9%)
  4. Nitrogen (N) (~12.8%)
  5. Temperature (~12.0%)
  6. Soil pH (~9.3%)

## 🚀 How to Run the Application

### Method 1: One-Click Script (Windows)
Double-click `run.bat` or run:
```cmd
run.bat
```
This automatically verifies the trained model and starts the web application in your default browser.

### Method 2: Command Line (Streamlit)
```bash
python -m streamlit run app.py
```
Or:
```bash
streamlit run app.py
```
Open `http://localhost:8501` in your browser.

**Features in the Web App:**
- Interactive number sliders/inputs for soil nutrients and climate parameters.
- **Quick Presets** in the sidebar (Rice, Coffee, Cotton, Apple, Chickpea) to test with one click.
- Top recommendation with percentage confidence score and top 3 alternative crops.
- Collapsible model analytics expander with feature importance and confusion matrices.

### Method 3: CLI Predictor (No UI Needed)
Run standalone predictions directly from your terminal:

**Interactive mode:**
```bash
python predict.py
```

**Argument mode:**
```bash
python predict.py --N 90 --P 42 --K 43 --temp 21.0 --ph 6.5 --rain 200.0
```

**Example output:**
```text
=============================================
🌾 Recommended Crop: RICE (91.5% confidence)
=============================================
Top 3 Candidates:
  1. Rice            :  91.5%
  2. Jute            :   8.5%
  3. Apple           :   0.0%
=============================================
```

## 🔄 How to Retrain the Model

To retrain the Random Forest model and regenerate all charts and evaluation metrics in `results.json` and `figs/`:

```bash
python train.py
```

This will:
1. Load `data/Crop_recommendation.csv`.
2. Evaluate Baseline, Gaussian Naive Bayes, and Random Forest models with 5-fold cross validation.
3. Save the best performing model bundle to `model/crop_model.pkl`.
4. Output benchmark and confusion logs to `results.json`.
5. Generate 8 high-resolution analytical plots in `figs/`.

## 🌾 Input Feature Guide

| Parameter | Feature Name | Allowed Range | Unit | Typical Influence |
|---|---|---|---|---|
| **Nitrogen** | `N` | 0 – 140 | Ratio / kg/ha | Leaf growth and vegetative health |
| **Phosphorus** | `P` | 5 – 145 | Ratio / kg/ha | Root development and blooming |
| **Potassium** | `K` | 5 – 205 | Ratio / kg/ha | Water regulation and disease resistance |
| **Temperature** | `temperature` | 8.0 – 44.0 | °C | Thermal tolerance for germination and growth |
| **Soil pH** | `ph` | 3.5 – 10.0 | pH scale | Nutrient availability in soil |
| **Rainfall** | `rainfall` | 20.0 – 300.0 | mm | Water availability and moisture |

## 🌿 Supported Crop Varieties (22)

The system is trained to distinguish between 22 major crop species:
- **Cereals & Grains:** Rice, Maize
- **Pulses & Legumes:** Chickpea, Kidneybeans, Pigeonpeas, Mothbeans, Mungbean, Blackgram, Lentil
- **Fruits:** Pomegranate, Banana, Mango, Grapes, Watermelon, Muskmelon, Apple, Orange, Papaya, Coconut
- **Commercial & Cash Crops:** Cotton, Jute, Coffee
